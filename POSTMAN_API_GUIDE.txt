1. SYSTEM OVERVIEW & ARCHITECTURE
================================================================================
This personalized RSVP system gives every invited guest or family a unique,
cryptographically secure 12-character random token.

Key Features:
- Secure URLs: Guest URLs look like:
  https://weeding-test.onrender.com/rsvp/0qasLjTBkVcZ
- No database IDs, phone numbers, or guest names are exposed in the link.
- Zero Login: Guests do not need passwords, accounts, or email verification.
- Family Attendance: Family invitations include individual checkboxes for every
  family member so each person's attendance is tracked accurately.
- Personalized Welcome: When opened on a phone or desktop, the page warmly
  welcomes the guest by name at the top of the royal invitation arch.
- Manual Code Entry: Guests who open the main homepage can click
  "Have a personalized invitation code?" and enter their 12-character token.

4.6 Admin: Soft-Disable / Enable Invitation
--------------------------------------------------------------------------------
Allows you to disable an invitation link without deleting the record. When a
guest visits an INACTIVE link, the website informs them that the invitation
is no longer active and gives them a button to contact the host.

- Method: PATCH
- URL: {{baseUrl}}/api/guests/1/status
- Header: Content-Type: application/json

To Disable:
Request Body (raw JSON):
{
  "status": "INACTIVE"
}

To Re-Enable:
Request Body (raw JSON):
{
  "status": "ACTIVE"
}

Expected Response (200 OK):
{
  "id": 1,
  "name": "Sharma Family",
  "status": "INACTIVE",
  ...
}

6. ERROR CODES & TROUBLESHOOTING
================================================================================
1. HTTP 400 (Bad Request):
   - Cause: Missing "name" field or invalid JSON syntax.
   - Solution: Ensure the "name" field is non-empty and your JSON is valid.
     Make sure the Header "Content-Type: application/json" is included.

2. HTTP 404 (Not Found):
   - Cause: The 12-character token does not exist in the database, or an invalid
     guest ID was requested.
   - Solution: Verify the token or ID by running GET /api/guests.

3. HTTP 403 (Forbidden):
   - Cause: The invitation was soft-disabled (status is INACTIVE).
   - Solution: Use PATCH /api/guests/{id}/status with {"status": "ACTIVE"} to re-enable.

4. Free Tier Sleep Delay (Render):
   - If no traffic has arrived for ~15 minutes, Render may take 30-50 seconds to
     wake up the container on the first request. Subsequent requests are fast.
